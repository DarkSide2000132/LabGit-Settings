# LabGit-Settings

## Назначение проекта

Проект создан для изучения возможностей GitHub и системы контроля версий Git.
В ходе лабораторной работы выполняются создание репозитория, организация
каталогов, настройка правил исключения и обработка различных типов файлов.

## Структура каталогов

- `src/` — исходный код программы.
- `docs/` — документация проекта.
- `tests/` — тестовые материалы.
- `assets/` — вспомогательные ресурсы проекта.

## Файлы настроек

- `.gitignore` — содержит правила исключения ненужных файлов и каталогов.
- `.gitattributes` — задаёт правила обработки текстовых и бинарных файлов.
- `README.md` — содержит описание проекта.

## Исключаемые файлы

Исключаются каталоги сборки `build/`, `bin/`, `obj/`,
временные файлы `*.tmp`, `*.temp`, `*.bak`, журналы `*.log`,
локальные настройки `.env`, папки `.vs/` и `.vscode/`,
пользовательские файлы `*.user` и `*.suo`, а также `TestResults/`.

## Настройки репозитория

Работа выполняется через веб-интерфейс GitHub.
Изменения фиксируются отдельными коммитами с описанием выполненных действий.
Для обработки файлов используется `.gitattributes`,
а для исключения ненужных файлов — `.gitignore`.
